# RIXA ATAR Mentor

English-language one-to-one academic mentoring for Australian high school students.

## Website

The English site is published at:

https://rixa-atar-mentor.yoneriku19.chatgpt.site

## Support

- ATAR subject tutoring and assessment planning
- A forward-looking plan for each subject and each student
- Essay structure, thesis, evidence, analysis, drafting, and revision coaching
- University course, prerequisite, scholarship, and application planning
- Weekly study routines and accountability

Both monthly plans support ATAR classes:

- Essentials — $200/month, one 60-minute session each week
- Mentor — $400/month, one 90-minute session each week plus deeper planning and accountability

The personal university outcomes shown on the site are Riku Yoneyama’s own 2023 application results, not a guarantee of future student outcomes.
